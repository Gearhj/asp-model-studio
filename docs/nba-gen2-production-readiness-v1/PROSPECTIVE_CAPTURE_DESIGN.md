# Prospective 2026-27 NBA team-box capture hook

The hook remains uninstalled. Its future owner runs only after a governed game
revision reaches FINAL. It captures one authorized season/team-box response or
bounded game repair, retains raw content-addressed bytes, request parameters,
headers, retrieval and source clocks, physical digest, schema fingerprint, and
correction lineage.

Admission requires exactly two opponent rows, stable team/game orientation,
score and possession-component reconciliation, explicit overtime minutes,
separate regular-season/playoff scope, and no target-game use in predictors.
A corrected revision supersedes through lineage without deleting the predecessor.
Features update only for forecasts whose cutoff follows the admitted final.

Ceilings, source rights, endpoint choice, cadence, and retention must be bound in
a separately authorized deployment. The hook performs no AISP, sportsbook,
decision, position, or settlement work.
