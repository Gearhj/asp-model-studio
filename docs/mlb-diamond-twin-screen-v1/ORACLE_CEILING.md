# Named-defense oracle ceiling

The oracle supplied the actual eight starting defenders and their actual listed positions to a player-position effect model fitted only on the earlier development interval. It did not use target outcomes to select participants, but the participants themselves are post-cutoff oracle evidence and the Silver source is quarantined.

V18 conditional BIP log loss was 0.606386; the oracle was 0.608209. V18 eight-class log loss was 1.479584; the oracle was 1.480765. All four proper-score differences were harmful and their calendar-date intervals excluded zero in the harmful direction.

At the game proxy level, V18 winner log loss was 0.67144 and the oracle was 0.70027. V18 Brier was 0.23807 and the oracle was 0.25031. Candidate-minus-baseline paired intervals were +0.01102 to +0.04417 for log loss and +0.00425 to +0.01933 for Brier. Home-score, total, and margin MAE also worsened; away-score MAE was directionally worse with an interval spanning zero.

This ceiling is not negligible in mechanical magnitude; it is predictively adverse. That distinction closes the named-identity route more strongly than a tiny neutral effect would. It does not answer whether measured spatial defense or interaction-specific defensive skill has value because those inputs were absent.
