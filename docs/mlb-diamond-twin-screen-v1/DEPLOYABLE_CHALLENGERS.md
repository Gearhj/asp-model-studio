# Cheap deployable challenger results

The only pregame-like challenger available without inventing data was a deterministic carry-forward rule: for each team, use the latest complete starting defense from a strictly earlier calendar date. Same-date games were ineligible donors. It covered all 47,286 assessment PAs, but its source publication timing is not certified and its Silver source is not approved for model training.

The carry-forward adjustment worsened conditional BIP log loss by 0.001854 (95% +0.001108 to +0.002577) and eight-class log loss by 0.001200 (+0.000712 to +0.001685). It therefore fails on numerical evidence before the authority limitation is considered.

No GB/FB, batter-direction, spatial, or catcher-quality challenger was run. Using pitch mix as a proxy for GB/FB, batting average as a proxy for spray, or catcher identity as a proxy for framing would answer different questions and violate the frozen feature contract.
