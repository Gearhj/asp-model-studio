## Phase 2 interpretation

- Every row marked high risk or critical needs behavioral cross-user tests before remediation can be called complete.
- List filtering and ID-addressed authorization must be tested separately.
- File-backed stores need an authoritative resource-to-project/owner mapping before access checks can be reliable.
- Code execution, async analytics, recovery scanning, and filesystem-path responses need dedicated threat models in addition to ordinary RBAC.
