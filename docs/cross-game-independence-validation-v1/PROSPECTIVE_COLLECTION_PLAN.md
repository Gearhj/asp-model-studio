# Prospective collection plan

No scheduler or collection job is created by this study. A later authorized collection should retain, before outcomes:

- canonical sport/game/team identities and exact scheduled start;
- exact controlling forecast ID, model/configuration, horizon and revision;
- physical source cutoff, creation, publication and consumer-import clocks;
- each leg's probability semantics and tie treatment;
- shared-team/doubleheader, venue/geography, weather-input, tournament/postseason, standings/incentive, player/roster dependency and source-incident flags;
- the category registered before outcomes and a stable record of exclusions.

After outcomes, join governed final identities without changing the frozen forecast revision. Repeat the v1 two-leg study at the frozen thresholds. Do not search categories until one passes. Three-plus-leg assessment requires a separately frozen design.
