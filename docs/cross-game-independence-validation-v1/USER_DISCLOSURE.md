# Proposed user-facing disclosure

## Current state

> Cross-game probability is unavailable. Multiplying separate game probabilities assumes their errors are independent. Our historical research has not yet met the precision and calibration requirements for this category.

## Future text only after a category passes

> Research estimate under an independence assumption. This probability multiplies two separately produced game forecasts; it does not come from a shared simulation population. Shared teams, linked incentives, uncertain shared inputs and other known dependencies are excluded. The estimate has no empirical joint draw count and is not wagering authority.

The second form is proposed language, not authorization to enable a display now.
