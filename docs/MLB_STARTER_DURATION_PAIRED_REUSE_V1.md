Review date: 2026-09-11. Scope: the four named repositories, one attempted fifth starter-removal repository, and Spencer's methodological article. Public source/document inspection only; no downloaded code was executed, no package was installed, no sports-provider endpoint was called, and no model was fitted. External code availability is not a prerequisite for publishing a legitimate eligible pair.

## Methodological use, not a new fit

[Scott Spencer's analysis](https://ssp3nc3r.github.io/post/visual-exploration-of-starting-pitcher-duration/) is useful for the BF clock, risk-set interpretation, nonlinear workload, and distinction between removal and surviving to game end. It studies 2017 with conditional R/Stan models and LOO/model diagnostics, not our chronological prospective game comparison; its first model explicitly ignores censored complete games. No code or coefficients were copied.

The local adapter must keep the existing declaration: after at least one completed PA and only at a supported active next-pitching opportunity, condition to `REMOVAL / (CONTINUE + REMOVAL)`. The simulator owns termination. BF is not pitch count; an observed future hook or future run total is never an input. The article is not authority to infer an optimal managerial policy or import a new censoring assumption.

## Small cold-start / MiLB backlog — not authorized work in this pilot

1. Preserve the difference between **verified zero prior starts**, limited retained history, and source failure. A missing MLB table must not silently become career TBF=0. Quantify future performance separately for no-history, sparse-history and conventional-usage groups; current missing-value branches remain frozen.
2. If separately authorized, translate component sufficient statistics using canonical IDs, actual exposures, league/level/park/year and strictly pre-cutoff availability. Fit and validate translations on earlier Development transitions, not on this prospective pilot; do not copy LSTMLB's level constants or treat its default unknown-level→AAA as evidence.
3. Separate skill translation from usage: MiLB K/BB/BIP information does not reveal an announced MLB workload restriction, opener role, injury availability or bullpen readiness. Preserve absent evidence explicitly. Any later duration prior needs held-out BF/calibration/coverage checks and complete fitted artifacts before an independent game-level evaluation.
