# Player archetype report

V18 supports coarse, continuous style features: batter handedness and rolling outcomes; pitcher handedness, strikeout/walk/whiff rates, fastball/breaking/offspeed shares, and average fastball velocity. The repository also contains an executable clustering seam using those pitcher fields.

No new archetype challenger was admitted in this program. The earlier V19 cluster fits used the same baseline history whose suspended/resumed-game chronology is uncertified. Reusing those metrics would convert a mechanical fit into an invalid predictive claim. The retained population also lacks pitch shape, command-location distributions, contact geometry, and certified pregame role changes needed for richer baseball archetypes.

The smallest honest next archetype assessment is conditional on the completion-aware baseline/history repair. It should reuse the already bounded cluster definitions, refit only chronological Development folds, and require improvement over both exact V18 and the corresponding continuous-feature model. No cluster should be promoted solely because it is interpretable.
