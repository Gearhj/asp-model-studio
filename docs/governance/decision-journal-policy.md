# ATLAS Decision Journal Policy

The Decision Journal is the audit trail for material modeling and experimental-design decisions.

## What Belongs in the Journal

- Target and response definition changes
- Feature inclusion and exclusion decisions
- Missing-value and outlier-treatment choices
- Split, balancing, blocking, randomization, sample-size, and launch decisions
- Model selection, champion promotion, and final model save events
- Challenge Mode overrides and user rationale
- Custom Python edits that alter governed logic

## What Should Be Summarized Separately

Routine UI events, repeated save events, and low-value click history should not appear in executive reports. ATLAS generates a material decision summary for documents and keeps the full timeline available in the appendix or Decision Journal page.

## Rationale Requirements

Overrides should include a user rationale whenever the action contradicts ATLAS recommendations, governance policy, or expected statistical practice.
