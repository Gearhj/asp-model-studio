# ATLAS Governance Report Template

The governance report should summarize the final governed decision rather than dump workflow objects.

## Report Structure

| Section | Purpose |
|---|---|
| Executive Summary | Business-friendly summary of the model or experiment and launch recommendation |
| Evidence Readiness | Checklist of required governance artifacts and missing evidence |
| Workflow Decisions | Material decision summary, not every UI event |
| Data Handling | Source, lineage, data quality, missing values, outliers, exclusions |
| Model or Experiment Evidence | Candidate records, champion selection, performance, stability, interpretation |
| Compliance Considerations | Fair lending, FCRA/ECOA, SR 11-7, privacy, monitoring, limitations |
| Appendices | Full decision journal, experiment details, notebook references, technical outputs |

## Presentation Standard

Use professional HTML tables, status badges, callouts, timelines, and section summaries. Do not emit raw JSON, raw Markdown pipe tables, or unsanitized user-provided HTML in exported reports.
