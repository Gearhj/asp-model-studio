# Experimental Design Workflow

The experimental design workflow is a guided statistical workbench for designing, validating, launching, and documenting controlled experiments.

## Core Stages

1. Project Context
2. Research Question
3. Factors
4. Levels
5. Blocking
6. Randomization
7. Sample Size
8. Monte Carlo Simulation
9. Experiment Run Plan
10. ANOVA
11. Optimization
12. Documentation

## Design Principles

- Each page should compute a shared analysis object first.
- Interactive UI and governance reports should render from the same analysis object.
- Governance language should be editable, auto-populated, and available near the top of the page.
- Analytical visuals should dominate the page; audit text should be collapsed unless editing is needed.
- Bottom navigation should save the current step, advance, update progress, and scroll to top.

## Key Outputs

- Factor hierarchy
- Treatment matrix
- Blocking recommendation
- Randomization diagnostics
- Sample size and power analysis
- Monte Carlo readiness and launch risk
- Experiment run plan
- ANOVA-ready model specification
- Optimization recommendation
- Governance-ready experiment report
