## Outcome-blind deviations and grouping

For each reference let d_home = V18_home_mean - reference_home_mean and d_away likewise. Signed total deviation is d_home+d_away; signed home-margin deviation is d_home-d_away. Retain signed and absolute values. A forecast is UNUSUAL for that reference if max(abs(d_home), abs(d_away)) >= 2.0 runs; otherwise ORDINARY. Missing references are UNSUPPORTED, never ordinary. Use this one fixed rule separately for each definition, with no threshold or blend-weight search.

The grouping concerns forecast means available before the target, not the largest individual simulation draw or an error observed afterward. Retain original distribution quantiles/tails separately as context; no draws are clipped or removed.
